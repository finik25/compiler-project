# Спецификация языка MiniCompiler (Sprint 1)

## 1. Общие сведения
- **Кодировка:** UTF-8
- **Регистрозависимость:** да
- **Максимальная длина идентификатора:** 255 символов
- **Целые числа:** 32-битные знаковые, диапазон [-2³¹, 2³¹-1]
- **Числа с плавающей точкой:** стандартное представление IEEE 754 (64-bit)

## 2. Лексическая грамматика (EBNF)

```ebnf
(* Токены *)

(* Ключевые слова *)
keyword = "if" | "else" | "while" | "for" | "int" | "float"
        | "bool" | "return" | "true" | "false" | "void"
        | "struct" | "fn" ;

(* Идентификаторы *)
letter = "A" | "B" | ... | "Z" | "a" | "b" | ... | "z" ;
digit = "0" | "1" | ... | "9" ;
identifier = letter ( letter | digit | "_" )* ;

(* Литералы *)
integer_literal = digit+ ;
float_literal = digit+ "." digit+ ;
string_literal = '"' ( character - '"' )* '"' ;   (* простые строки, escape не обязательны *)
boolean_literal = "true" | "false" ;

(* Операторы (одно- и двухсимвольные) *)
inc_op      = "++" ;
dec_op      = "--" ;
add_op      = "+" | "-" ;
mul_op      = "*" | "/" | "%" ;
rel_op      = "==" | "!=" | "<" | "<=" | ">" | ">=" ;
log_op      = "&&" | "||" ;
not_op      = "!" ;
assign_op   = "=" ;
comp_assign = "+=" | "-=" | "*=" | "/=" ;  (* составные присваивания *)

(* Разделители *)
delimiter = "(" | ")" | "{" | "}" | "[" | "]" | ";" | "," | ":" ;

(* Комментарии *)
single_line_comment = "//" , { character - newline } , newline ;
multi_line_comment = "/*" , { character - "*/" } , "*/" ;  (* без вложенности *)

(* Пробельные символы *)
whitespace = " " | "\t" | "\n" | "\r" | "\r\n" ;
newline = "\n" | "\r\n" ;
```

## 3. Токены и их представление

При лексическом анализе каждый токен относится к одному из следующих типов:

| Тип токена          | Пример лексемы | Примечание                         |
|---------------------|----------------|------------------------------------|
| `KW_IF`             | `if`           | ключевое слово                     |
| `KW_ELSE`           | `else`         |                                    |
| `KW_WHILE`          | `while`        |                                    |
| `KW_FOR`            | `for`          |                                    |
| `KW_INT`            | `int`          |                                    |
| `KW_FLOAT`          | `float`        |                                    |
| `KW_BOOL`           | `bool`         |                                    |
| `KW_RETURN`         | `return`       |                                    |
| `KW_TRUE`           | `true`         |                                    |
| `KW_FALSE`          | `false`        |                                    |
| `KW_VOID`           | `void`         |                                    |
| `KW_STRUCT`         | `struct`       |                                    |
| `KW_FN`             | `fn`           |                                    |
| `IDENTIFIER`        | `counter`      | имя переменной/функции              |
| `INT_LITERAL`       | `42`           | целое число                        |
| `FLOAT_LITERAL`     | `3.14`         | число с плавающей точкой            |
| `STRING_LITERAL`    | `"hello"`      | строковый литерал                   |
| `BOOLEAN_LITERAL`   | `true`         | булево значение                     |
| `INC_OP`            | `++`           | инкремент                          |
| `DEC_OP`            | `--`           | декремент                          |
| `PLUS`              | `+`            | сложение                           |
| `MINUS`             | `-`            | вычитание                          |
| `STAR`              | `*`            | умножение                          |
| `SLASH`             | `/`            | деление                            |
| `PERCENT`           | `%`            | остаток                            |
| `EQ`                | `==`           | равно                              |
| `NE`                | `!=`           | не равно                           |
| `LT`                | `<`            | меньше                             |
| `LE`                | `<=`           | меньше или равно                   |
| `GT`                | `>`            | больше                             |
| `GE`                | `>=`           | больше или равно                   |
| `AND`               | `&&`           | логическое И                       |
| `OR`                | `||`           | логическое ИЛИ                     |
| `NOT`               | `!`            | логическое НЕ                      |
| `ASSIGN`            | `=`            | присваивание                       |
| `ADD_ASSIGN`        | `+=`           | сложение с присваиванием            |
| `SUB_ASSIGN`        | `-=`           | вычитание с присваиванием           |
| `MUL_ASSIGN`        | `*=`           | умножение с присваиванием           |
| `DIV_ASSIGN`        | `/=`           | деление с присваиванием             |
| `LPAREN`            | `(`            | левая круглая скобка                |
| `RPAREN`            | `)`            | правая круглая скобка               |
| `LBRACE`            | `{`            | левая фигурная скобка               |
| `RBRACE`            | `}`            | правая фигурная скобка              |
| `LBRACKET`          | `[`            | левая квадратная скобка             |
| `RBRACKET`          | `]`            | правая квадратная скобка            |
| `SEMICOLON`         | `;`            | точка с запятой                     |
| `COMMA`             | `,`            | запятая                            |
| `COLON`             | `:`            | двоеточие                          |
| `END_OF_FILE`       |                | маркер конца файла                  |
| `ERROR`             |                | лексическая ошибка                  |

## 4. Примеры

### Исходный код
```c
fn main() {
    int x = 10;
    x++;
    // increment
    return x;
}
```

### Ожидаемый вывод токенов
```
1:1 KW_FN "fn"
1:4 IDENTIFIER "main"
1:8 LPAREN "("
1:9 RPAREN ")"
1:10 LBRACE "{"
2:5 KW_INT "int"
2:9 IDENTIFIER "x"
2:11 ASSIGN "="
2:13 INT_LITERAL "10" 10
2:15 SEMICOLON ";"
3:5 IDENTIFIER "x"
3:6 INC_OP "++"
3:8 SEMICOLON ";"
4:5 KW_RETURN "return"
4:12 IDENTIFIER "x"
4:13 SEMICOLON ";"
5:1 RBRACE "}"
6:1 END_OF_FILE ""
```

## 5. Примечания
- Комментарии игнорируются лексером, т.е. не порождают токенов.
- Пробельные символы также игнорируются.
- В случае обнаружения недопустимого символа генерируется токен `ERROR` с указанием позиции, и сканирование продолжается.
